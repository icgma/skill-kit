How to install

把技能装进你的 Agent

本库里的技能是标准 Agent Skill：一个目录 + SKILL.md。 复制到对应位置后，Claude Code、Cursor、Codex、pi 等会按描述自动选用。

1. 从本站复制

  1. 打开某个技能。
  2. 点「复制 SKILL.md」或「下载 ZIP」（含该技能全部文件）。
  3. 按下面的路径放到本地。

2. 放置路径

工具 个人全局 仅当前项目
Claude Code ~/.claude/skills/<name>/ .claude/skills/<name>/
Cursor ~/.cursor/skills/<name>/ .cursor/skills/<name>/
Codex / pi / 多数 agent ~/.agents/skills/<name>/ .agents/skills/<name>/

Windows 把 ~ 换成 %USERPROFILE%，例如 %USERPROFILE%\.agents\skills\css-professor\。

3. 目录长什么样

css-professor/
  SKILL.md
  workflows/     ← 可选，分步流程
  references/    ← 可选，背景知识
  templates/     ← 可选
  scripts/       ← 可选

最少只要 SKILL.md。多文件技能请整夹复制，不要只拷正文。

4. 技能如何被选中

Agent 先读 YAML 里的 description。把「做什么」和「何时用」写清楚， 比写一长段原理更重要。改完技能后一般不用重启，下一轮对话就会重新加载。
